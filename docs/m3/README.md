# Milestone 3 materials

| File | What it is |
|---|---|
| [`report/M3_Team3_BillBridge.html`](report/M3_Team3_BillBridge.html) | Source of the M3 report (oversight design, events and state, test results, production cost). Team names and contributions are placeholders to fill in |
| [`diagrams/`](diagrams/) | Component, state and deployment diagrams (SVG + PNG), generated by `make_diagrams.py` |
| [`test_evidence.md`](test_evidence.md) / [`.json`](test_evidence.json) | Output of `python scripts/m3_cases.py`: input, expected, actual and evidence for the four M3 cases |

Rebuild:

```bash
python docs/m3/diagrams/make_diagrams.py
python scripts/m3_cases.py
node scripts/render_report.js "$PWD/docs/m3/report/M3_Team3_BillBridge.html" M3_Team3_BillBridge.pdf   # needs Playwright
```
